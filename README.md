# TEST — 彈珠台遊戲

單一檔案的 HTML5 Canvas 彈珠台,不需安裝任何東西。直接用瀏覽器開啟 `index.html` 即可。

## 三個檯面

畫面上方的按鈕或鍵盤 `1` / `2` / `3` 可隨時切換(切換會重新開始),每個檯面各自記錄最高分。

| 檯面 | 特色 |
|------|------|
| 1 經典 | 三個大彈跳器 + 小圓柱,穩定好上手 |
| 2 霓虹彈跳 | 頂部導流板、150 分大彈跳器,以及一個會左右移動的 200 分靶 |
| 3 釘子雨 | 滿檯小釘(每顆 5 分),球像鋼珠一樣亂竄,下方有三個彈跳器 |

## 操作

| 動作 | 鍵盤 | 手機 |
|------|------|------|
| 發射(按住蓄力、放開發射) | 空白鍵 | 「發射」按鈕 |
| 左擋板 | ← / Z / A | 「左」按鈕 |
| 右擋板 | → / M / L | 「右」按鈕 |
| 換檯面 | 1 / 2 / 3 | 點上方按鈕 |
| 重新開始(Game Over 後) | 空白鍵 | 「發射」按鈕 |

## 排行榜

- 每個檯面各有一份前 10 名排行榜,點上方 🏆 隨時查看(開啟時遊戲會暫停)。
- 遊戲結束時,分數進榜會跳出輸入名字的視窗(最多 10 字),儲存後直接顯示你的名次。
- 排行榜存在**這台裝置的瀏覽器**(localStorage),不同裝置或瀏覽器之間不會同步。

## 規則

- 共 3 顆球,球掉到底部就少一顆。
- 彈弓每次 +10,彈跳器分數標示在上面。
- 最高分存在瀏覽器的 localStorage。
- 蓄力條變綠(約 2/3 以上)才能把球發射到球檯頂端。
