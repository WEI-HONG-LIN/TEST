# TEST — 彈珠台遊戲

單一檔案的 HTML5 Canvas 彈珠台,不需安裝任何東西。

## 開始遊玩

直接用瀏覽器開啟 `index.html` 即可。

## 操作

| 動作 | 鍵盤 | 手機 |
|------|------|------|
| 發射(按住蓄力、放開發射) | 空白鍵 | 「發射」按鈕 |
| 左擋板 | ← / Z / A | 「左」按鈕 |
| 右擋板 | → / M / L | 「右」按鈕 |
| 重新開始(Game Over 後) | 空白鍵 | 「發射」按鈕 |

## 規則

- 共 3 顆球,球掉到底部就少一顆。
- 大彈跳器 +100、小圓柱 +25 / +50、彈弓 +10。
- 最高分會存在瀏覽器的 localStorage。
- 蓄力條變綠(約 2/3 以上)才能把球發射到球檯頂端。
